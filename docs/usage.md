# 使用与运行

| | 浏览器版 | Windows 本机版 |
| --- | --- | --- |
| 适合 | 在其他电脑打开链接，快速改稿 | 用已安装的 Illustrator 处理原生设计文件 |
| 运行依赖 | 近期桌面浏览器；自行构建需 Node.js 22+ | Windows、Node.js、已激活的 Illustrator、Windows PowerShell |
| 文件处理位置 | 当前浏览器 | 当前电脑的 Illustrator 工作副本 |
| 启动 | 构建后在 `online/` 执行 `npm start` | 仓库根目录执行 `node server.cjs` |
| 原生 AI 导出 | 可用 PDF 继续到 Illustrator 编辑 | 支持 |

## 带回 Illustrator

从工作台导出 PDF 后，用 Illustrator 的 **文件 → 打开** 打开 PDF，再用文字工具选中一行试改。以链接图稿方式「置入」时，Illustrator 选择的是置入对象。原稿已经转曲或本身就是图片时，需编辑路径、替换文字或返回带文字图层的源文件。对印刷敏感的工作请复核页数、画板尺寸、字体、颜色和透明效果。

## 字体与文本框

原稿内嵌字体有时只带用过的字形。如果新输入的字不在其中，选中该段并点击「匹配本机原字体」，在支持的浏览器中授权本机字体读取。需要可选本机字重时，优先使用桌面 Chrome 或 Edge。字号和行距使用 pt，几何属性输入框会标注对应单位。

## 图片与层级

矩形与一张图片重叠时，选中矩形并点击「从画板复制图片并原位裁切」。多张重叠时可从画板或对象列表选择源图。双击图片框可调整框内照片。左侧列表由上至下对应从前到后的绘制顺序。

## 本地数据和大文件

下载的文件可用于备份及跨设备移交。同一台设备上的其他浏览器使用独立存储。大文件可用容量取决于浏览器内存；保存前请留出足够磁盘空间，长时间编辑建议分阶段导出。

## 构建目录

- `web/` 为共享的工作台界面。
- `online/` 包含浏览器文档模型、格式适配器、构建脚本与静态预览服务。
- `server.cjs`、`engine.jsx`、`scene.cjs`、`scene.jsx` 提供 Windows 本机服务与 Illustrator 脚本。
- `assets/fonts/`、`vendor/` 提供构建使用的字体、库及其许可。
- `examples/` 是为本仓库创作的双页阅读架说明书及两张独立 SVG。
