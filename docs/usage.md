# 使用与运行

| | 浏览器版 | Windows + Illustrator 联动版 |
| --- | --- | --- |
| 适合 | 在其他电脑打开链接，快速改稿 | 用已安装的 Illustrator 处理原生设计文件 |
| 运行依赖 | 近期桌面浏览器；自行构建需 Node.js 22+ | Windows、Node.js、已激活的 Illustrator、Windows PowerShell |
| 文件处理位置 | 当前浏览器 | 当前电脑的 Illustrator 工作副本 |
| 启动 | 构建后在 `online/` 执行 `npm start` | 仓库根目录执行 `node server.cjs` |
| 原生 AI 导出 | 可用 PDF 继续到 Illustrator 编辑 | 支持 |

Windows x64 便携版使用浏览器版的格式引擎。完整解压后双击 **VectorWorkbench.exe**，可离线打开、编辑和导出。运行依赖、下载地址和构建方法见 [Windows 桌面版](../README.md#windows-桌面版)。

## 新建画板

首次新建使用 1000 × 1000 px。要保存常用规格，在新建窗口选择单位、填写宽高，勾选「设为默认尺寸」再点击「创建画板」。下次新建会带出这一组宽、高和单位。默认尺寸保存在当前浏览器或 Windows 应用的本机配置中。

## 调整文字间距

选中文字，在右侧「Photoshop 字距」输入数值或拖动滑块。单位是千分之一 em，与 Photoshop 的字距数值对应，例如 −40 表示收紧当前字号的 4%。「字间距 (pt)」可输入绝对距离。PSD 文字中单独设置的字距与手动字偶间距可随文字段保留；调整整层字距会保留段与段之间的差值。

若 PSD 记录了横排点文字的逐字排版位置，快改会用这些位置还原原文，并保留字对的光学微调。修改字距时，每个字符间隔按字号及输入值增减。新输入的字对或没有逐字记录的文件，使用当前字体和已有字距数据排版。

## 调整圆角

选中矩形或矩形图片框，在右侧「圆角」选择「四角统一」或「四角独立」。独立模式中，每个角都可输入毫米数或拖动滑块，输入 0 即为直角。切回统一模式时，四个角采用左上角的半径。

## 切换画板单位

在左侧「页面 → 画板单位」可直接切换当前画板的显示单位。按 Shift+O 进入画板工具后，同一选项在右侧「画板属性」。尺寸和标尺一起换算，当前画板的选择会保存到工程。PSD 使用原稿分辨率，普通画板按每英寸 96 像素换算。

## 带回 Illustrator

从工作台导出 PDF 后，用 Illustrator 的 **文件 → 打开** 打开 PDF，再用文字工具选中一行试改。以链接图稿方式「置入」时，Illustrator 选择的是置入对象。原稿已经转曲或本身就是图片时，需编辑路径、替换文字或返回带文字图层的源文件。对印刷敏感的工作请复核页数、画板尺寸、字体、颜色和透明效果。

## 字体与文本框

原稿内嵌字体有时只带用过的字形。如果新输入的字不在其中，选中该段并点击「匹配本机原字体」，在支持的浏览器中授权本机字体读取。需要可选本机字重时，优先使用桌面 Chrome 或 Edge。字号和行距使用 pt，几何属性输入框会标注对应单位。

## 图片与层级

矩形与一张图片重叠时，选中矩形并点击「从画板复制图片并原位裁切」。多张重叠时可从画板或对象列表选择源图。双击图片框可调整框内照片。左侧列表由上至下对应从前到后的绘制顺序。

## 本地数据和大文件

下载的文件可用于备份及跨设备移交。同一台设备上的其他浏览器使用独立存储。大文件可用容量取决于浏览器内存；保存前请留出足够磁盘空间，长时间编辑建议分阶段导出。

## 构建目录

- `web/` 为共享的工作台界面。
- `online/` 包含浏览器文档模型、格式适配器、构建脚本与静态预览服务。
- `server.cjs`、`engine.jsx`、`scene.cjs`、`scene.jsx` 提供 Windows 本机服务与 Illustrator 脚本。
- `assets/fonts/`、`vendor/` 提供构建使用的字体、库及其许可。
- `examples/` 是为本仓库创作的双页阅读架说明书及两张独立 SVG。

## 与 Photoshop 和 Illustrator 交换画板

按 **Shift+O** 进入画板工具。单击选择，拖动移动整块画板和内容，拖角点修改边界。按 **Alt** 拖动复制，双击画板进入内容编辑。右侧可输入名称、坐标和尺寸，左侧拖动列表调整导出页序；空间位置和页序分别保存。

- **PSD · 全部画板** 写入 Photoshop 原生画板组，包含名称、尺寸、相对位置与图层。普通 PSD 仍按单画板处理。画板外的可见图层会单独列出。浏览器只还原支持的图层类型和效果。
- **Illustrator 画板包 · ZIP** 包含 artwork.pdf 和 restore-artboards.jsx。完整解压，在 Illustrator 选择「文件 → 脚本 → 其他脚本」，运行 JSX，再将新文档另存为 .ai。脚本在自己的 Illustrator 中执行；网站不连接桌面程序。
- PDF 兼容 AI 可以按页打开。能读取原生画板表时保留名称和排布；缺少该表或版本不匹配时，按 PDF 页面尺寸和顺序排列。PDF 导出保留多页及本工作台的布局记录。
- 导出普通 PDF 时，投影使用带透明度的图像，文字与普通路径仍单独写入。Illustrator 直接读入渐变文字时可能生成轮廓；画板包会在 Illustrator 内重建本工具设置的原生渐变文字。

在「混合选项 → 投影」中，可拖动光源角度滑块或输入角度。距离按毫米计，水平和垂直偏移会同步更新。角度沿用 Photoshop 的光源方向，90° 时阴影向下，距离为 0 时仍会保留所选角度。

### 段落对齐和渐变透明度

选中文字，在右侧选择「左对齐」「居中」或「右对齐」。三个按钮调整每行在当前文本框里的位置。PSD 导入会读取文字层自身的对齐、手动行距和字间距；点文字的每条原始换行仍独立保留。双击在画板上输入时使用相同的对齐方式。

开启「混合选项 → 渐变填充」后，可分别指定起点和终点的不透明度。将终点设为 0% 即可淡出到透明；下方棋盘格可预览效果。「不透明度」仍控制整个对象。导出 PSD 的渐变叠加及 Illustrator 画板包中的原生渐变会保留两个端点的透明度。

在「边框 / 描边」中可选择外部、居中或内部。文字和闭合图形新增描边时默认向外扩展；打开 PSD 会读取支持的图层描边位置，并按文件分辨率换算粗细。已经以居中描边保存的普通 SVG 路径保留其原始位置。

### 画板吸管

先选中要改色的文字或图形，在填充或描边旁点吸管，再点击画板上的目标颜色。取样使用该点的显示色，包括照片、渐变和透明色叠加在画板背景后的结果。多选时可将同一颜色一次应用到所选对象；渐变起点、终点和投影也有独立吸管。按 Esc 可取消。

### 画布旁的多页预览

打开多页文件时，画布右侧会显示页面缩略栏。滚轮浏览缩略图，单击切页，Shift + 滚轮直接翻页。选中页稍微放大，鼠标靠近时邻页也会轻微响应。窄屏改为画布上方的横向栏，支持滑动。键盘聚焦在缩略图时可用方向键或 Home / End 切换。

### 导出与画板命名

「导出」可选择图片或可编辑源文件，以及全部画板、当前画板或选中元素。多画板图片以 ZIP 下载，里面每张图单独命名；PNG 支持透明，JPG 将透明区域填为白色。默认 1× 优先使用导入 PSD 的分辨率，其余文稿按 96 px/in。工作台工程使用 .vqproj，重新打开后可继续编辑。左侧「重命名」、F2 或右键页面缩略图均可更改画板名称。

可将 PNG/JPG 直接拖入工作台。

导入 PSD 时，剪贴图层沿用同组下方基底的轮廓或透明度。可以在图层列表分别选择照片和基底，移动照片时保留框内裁切。导出 PSD 可保留连续图层的剪贴关系。导出 PDF 时，形状剪贴保留矢量边界，使用像素透明度的剪贴组会以图像保留外观。

PSD 原生线性、径向渐变形状填充与图层渐变叠加分别读取。支持的矩形和圆角矩形保留矢量形状、渐变色标和不透明度色标，轴对齐矩形可重新导出为 Photoshop 原生填充图层。复杂布尔蒙版、噪声与图案填充等使用可用的外观预览。
